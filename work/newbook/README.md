# خط أنابيب تفريغ كتاب «علم التجويد»

محرّك تفريغ ضوئي (OCR) مخصّص للمصوَّرات العربية المشكولة، بُني لكتاب:

> `new book/2_علم_التجويد_دكتور_يحيى_الغوثاني_.pdf` — ١٩٣ صفحة، ممسوح
> ضوئيًّا بلا أي طبقة نصّية.

> **متفرّع عن** `work/README.md` (محرّك فكّ ترميز خطوط PDF للجزأين الثاني
> والثالث). ذاك يعمل على PDF بنصّ رقمي مكتوب بخطوط CID غامضة، وهذا يعمل
> على صور ممسوحة — المشكلتان مختلفتان والحلّ مختلف.

## المدخلات والمخرجات

| | |
| --- | --- |
| **المدخل** | صور صفحات الكتاب من ملف PDF |
| **المخرجات** | `out/تفريغ_كتاب_علم_التجويد.txt` — التفريغ بالأمانة مع وسم المواضع المشكوكة |
| | `out/تفريغ_كتاب_علم_التجويد_مقروء.txt` — النسخة المقروءة (بلا ضبط غير موثوق) |
| | `out/كتاب_علم_التجويد_تفريغ.docx` — ملف وورد منظَّم |
| | `out/changes.json` — سجلّ كل تصحيح آلي ورقم صفحته |

**الشرح الكامل والقرارات المنهجية وحدود العمل:** `تقرير_التفريغ_والتدقيق.md`

## المكوّنات

| الملف | الوظيفة |
| --- | --- |
| `run_ocr.py` | يفرّغ كل صفحة إلى `json/pNNN.json`: كل كلمة بمربّعها وثقتها ووضع تقطيعها |
| `ocr_engine.py` | استخراج الصورة الأصلية، تطبيع الدقّة (رفع ×٣ بـESPCN بالتقسيط)، العتبة، واجهة Tesseract |
| `quran_ref.py` | مرجع المصحف: التطبيع، فهرس «المراسٍ»، واقتطاع الشواهد من المتن |
| `proofread.py` | المدقّق: المعجم العربي، تصحيح الحروف القاطع، تنقية الضبط البنيوية |
| `build_book.py` | التجميع النهائي: دمج المرورين، حذف الضجيج، إصلاح الشواهد، التدقيق، الإخراج |
| `make_docx.py` | توليد ملف الوورد |
| `fetch_refs.py` | تنزيل النماذج والمعاجم المرجعية إلى `refs/` و`sr_models/` |

## التشغيل

```bash
python fetch_refs.py     # مرة واحدة: نموذج Tesseract + المصحف + المعاجم
python run_ocr.py        # ≈٦ دقائق (١٩٣ صفحة)
python build_book.py
python make_docx.py
```

مفيد للتجربة السريعة:

```bash
python run_ocr.py --pages 20-40
python build_book.py --limit 21 --out out/تجربة.txt
python build_book.py --no-proof        # بلا تدقيق لغوي
```

## المبادئ التي تحكم المشروع

1. **لا تخمين.** الضبط لا يُخترع: الكلمة التي لها أكثر من مرشّح واحد
   تُترك كما هي. والموضع الذي لا تُقطع فيه المطابقة لا يُبدَّل.
2. **كل تصحيح مسجَّل.** `out/changes.json` يحمل كل تبديل مع صفحته ونوعه،
   فليس في المخرج شيء لا يمكن تعقّبه.
3. **الوسم بدل الإخفاء.** كل سطر ثقته أقلّ من ٤٠ موسومٌ بـ`⟨؟⟩`، فيعرف
   المدقّق البشري أين يركّز.
4. **المخرج حتميّ.** إعادة التشغيل تُنتج الملفّين نفسهما حرفيًّا.

## المراجع الخارجية (خارج git)

تُنزَّل إلى `refs/` و`sr_models/` عبر `fetch_refs.py`:

* `ara.traineddata` — نموذج Tesseract العربي الأدقّ (`tessdata_best`)
* `quran.json` — المصحف بالرسم العثماني (`risan/quran-json`)
* `arwiki.freqlist` — تكرارات كلمات ويكيبيديا العربية (`a3f/arabic-wordlists`)
* `quran.vocalized.wordlist` — مفردات القرآن مشكولة (المصدر نفسه)
* `ar.dic` — قاموس جذور عربي (`LibreOffice/dictionaries`)
* `ESPCN_x3.pb` — شبكة رفع الدقّة ×٣ (`fannymonori/TF-ESPCN`)

وسائط الصور (`json/`) خارج git أيضًا.
